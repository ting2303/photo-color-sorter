# 和 Lightroom Classic 整合的方案（v1.5 研擬）

目標：照片匯入 Lightroom 之後，**不用離開 Lightroom、不用改檔名**，就能依燈光顏色、段落、人數、星等挑圖和調色。

## 現在（階段 1 完成）能做到的

| 做法 | 優點 | 限制 |
|---|---|---|
| 改檔名 | 任何軟體都能排序 | 已匯入的照片不能用；檔名變長 |
| 寫入 Lightroom 標籤（RAW 旁的 .xmp） | 不改檔名，有星等、色標、關鍵字 | ① **只有 RAW**；② 已匯入的要手動「從檔案讀取中繼資料」；③ 色標名稱要和 Lightroom 的色標組一致（中文版可能變白色）；④ Lightroom 開著「自動寫入 XMP」時可能互相覆蓋 |

## 方案比較

### 方案 A：Lightroom 外掛程式（建議）
在 Lightroom 裡多一個選單「**圖庫 → 外掛程式額外項目 → 舞台色彩：分析選取的照片**」。

運作方式：
1. 外掛把選取照片的路徑交給 `PhotoColorSorter.exe`（用命令列模式，只讀照片、不寫任何檔案）。
2. 程式回傳分析結果（JSON：顏色、段落、人數、星等、代表張）。
3. 外掛**直接寫進 Lightroom 目錄**：星等、色標、「舞台色彩」關鍵字。

| 好處 | 說明 |
|---|---|
| **JPG 也能用** | 寫進 Lightroom 目錄，不用改照片檔案，前面「JPG 不寫」的限制就沒了 |
| 已匯入的照片直接更新 | 不用再「從檔案讀取中繼資料」 |
| 色標一定是紅色 | 外掛用 Lightroom 內部的色標代號，不受中文版色標名稱影響 |
| 可以在 Lightroom 裡復原 | 寫入包成一個步驟，Lightroom 的「編輯 → 還原」（Ctrl+Z）一次撤銷 |
| 不和「自動寫入 XMP」打架 | 由 Lightroom 自己寫目錄，它要不要同步到 XMP 照它的設定 |
| 自動建立「智慧型收藏集」 | 例如「舞台色彩 / 膚色藍」「每段代表張」「3 星」，點一下就篩好 |

| 成本與風險 | 說明 |
|---|---|
| 要寫 Lua（Lightroom SDK） | 約 300～500 行；外掛資料夾 `舞台色彩.lrplugin` 放在 ZIP 裡，使用者在「檔案 → 外掛程式管理員」加入一次 |
| **我無法在這台電腦測 Lightroom** | 每一版都需要你實機測（照清單 15 分鐘左右） |
| 版本相容性 | 用 Lightroom Classic 長期穩定的 SDK 功能（讀路徑、`setRawMetadata`、關鍵字、智慧型收藏集），不依賴新版功能 |
| 主程式要多一個命令列模式 | `--json`：輸出分析結果；改動小，可以寫自動測試 |

### 方案 B：只附「智慧型收藏集」與「篩選器預設」檔
不寫外掛，ZIP 裡附幾個 Lightroom 可以匯入的設定檔（依「舞台色彩」關鍵字、星等、紅標自動篩選）。

- 好處：做法簡單、沒有程式碼在 Lightroom 裡執行。
- 限制：仍然只有 RAW 有關鍵字；匯入步驟要使用者自己做，每種顏色一個收藏集要一個個匯入。
- 適合：先做出來，方案 A 完成後也還用得到（外掛會自動建立同樣的收藏集）。

### 不建議的做法
- **直接改 Lightroom 目錄檔（.lrcat）**：那是 SQLite 資料庫，Lightroom 開著時改會損壞目錄，Adobe 也不支援。
- **把標籤寫進 JPG 檔案本身**：違反「不修改照片」的承諾（你在階段 1 已經選了不寫）。外掛可以達到同樣效果又不動檔案。

## 建議的 v1.5 範圍

1. **v1.5 一定做**（已完成或進行中）：RAW 寫入 .xmp、人數關鍵字、點檔名開照片。
2. **v1.5 加做方案 A 外掛（第一版）**：
   - 選單：「分析選取的照片並寫入標籤」「移除『舞台色彩』標籤」
   - 寫入：星等（只補空的）、紅標（只補空的）、關鍵字（膚色／整體／段落／人數／亮度／代表張）；色標依人或依背景
   - 自動建立智慧型收藏集組「舞台色彩」：每種膚色、每種整體顏色、代表張、3 星
   - 主程式新增 `--json` 輸出與測試
   - 你用 Lightroom 實機測試清單驗收
3. **之後再看**：方案 B 的預設檔、依「調色起點」建議套用白平衡預設（數值還不夠準，先不做）。

## 外掛的實機測試會檢查什麼
- 選 20 張（RAW 和 JPG 混合）→ 執行 → 星等、紅標、關鍵字都出現，JPG 也有
- 已有星等、色標的照片保留原值
- Ctrl+Z 一次撤銷整批
- 智慧型收藏集建立在「舞台色彩」組裡，數量和程式的分析報告一致
- 「移除『舞台色彩』標籤」只移除本工具加的關鍵字，不碰其他關鍵字
- 選 500 張時 Lightroom 不會卡住（外掛在背景執行並顯示進度）
