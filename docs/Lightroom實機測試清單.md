# 階段 1：Lightroom Classic 實機測試清單

寫入 Lightroom 標籤的功能只在電腦上用程式驗證過（XML 讀回、復原、修圖設定不被改到），**還沒有在 Lightroom 裡實際看過**。請照下面步驟測一次，把每一項的結果（✔／✘＋截圖）告訴我。

全部步驟都用**複製出來的測試資料夾**，不要用正式照片。

## 準備

1. 準備一個 RAW 測試資料夾，例如 `D:\測試\xmp測試`，從某場活動複製 **10～20 張 ARW**（有沒有同名 JPG 都可以）。
2. 從其中挑 **2 張**，先在 Lightroom 給星等和色標，再「中繼資料 → 將中繼資料儲存至檔案」（`Ctrl+S`），讓它們有 Lightroom 自己的 `.xmp`。
   然後在 Lightroom 把這個資料夾**移除**（右鍵資料夾 →「移除」，不是刪除檔案）。
3. 執行桌面 `PhotoColorSorter_v1.5預覽` 資料夾裡的 `PhotoColorSorter.exe`（標題會顯示 v1.4.0，正式發布前才改版本號）。

## A. 新匯入的照片

1. 程式選測試資料夾 → ① 分析 → 進階設定 → 輸出方式選「**寫入 Lightroom 標籤**」。
   - [ ] 按鈕變成「② 寫入標籤」，表格最右欄顯示像 `★★ 紫標 粉/藍 S03 2人 代表` 的摘要
   - [ ] 「Lightroom 色標」選「**依人（膚色）**」
2. 按「② 寫入標籤」→ 是。
   - [ ] 完成視窗寫「新建 N 個 .xmp、合併 2 個」，「2 張保留原本的星等或色標」
   - [ ] 資料夾裡每張 ARW 旁邊都有同名 `.xmp`，**ARW 檔案的修改日期沒變**
3. 在 Lightroom 匯入這個資料夾（新增，不要複製）。
   - [ ] **星等**：圖庫格線上看得到 1～3 星
   - [ ] **色標**：臉被藍光照到的照片是**藍色**色標、粉紅光是**紫色**、橙光是**黃色**；臉是白光（正常膚色）的沒有色標
     （⚠ 這項最需要確認：如果顯示成**白色**，代表你的 Lightroom 色標組名稱和程式不同。請到 Lightroom「中繼資料 → 色標組 → 編輯」看五個名稱，填到程式進階設定的「色標名稱」，再測一次，並把名稱告訴我）
   - [ ] **過濾器**：圖庫上方過濾器列點「藍色」色標，只剩藍標的照片
   - [ ] **關鍵字**：關鍵字清單裡有「舞台色彩」，展開後有 膚色／整體／段落／人數／亮度／代表張
   - [ ] 點「舞台色彩 → 整體 → 藍」右邊的箭頭，只篩出整體藍色的照片
   - [ ] 步驟 2 先設好星等和色標的 2 張，**還是你原本設的**，修圖設定也還在

## A2. 依背景
1. 在程式按「↶ 復原上一次」，「Lightroom 色標」改選「**依背景（整體）**」，再寫入一次；在 Lightroom 全選 →「從檔案讀取中繼資料」。
   - [ ] 色標變成整張照片的主色（藍色舞台 → 藍標）

## B. 已經匯入 Lightroom 的照片

1. 在程式按「↶ 復原上一次」→ 是。
   - [ ] 程式新建的 `.xmp` 被刪掉；原本那 2 張的 `.xmp` 恢復原狀
2. 在 Lightroom 全選這批照片 →「中繼資料 → 從檔案讀取中繼資料」。
   - [ ] 星等、色標、「舞台色彩」關鍵字消失；原本那 2 張的設定還在
3. 再用程式寫入一次，回到 Lightroom 全選 →「從檔案讀取中繼資料」。
   - [ ] 星等、色標、關鍵字又出現

## C. 自動寫入 XMP 的衝突（選做）

1. Lightroom「目錄設定 → 中繼資料」勾選「**自動將變更寫入 XMP**」。
2. 在 Lightroom 改其中一張的星等。
3. 程式按「↶ 復原上一次」。
   - [ ] 那一張出現在「沒有復原」清單，理由是「寫入後被其他程式改過」，檔案沒有被刪或覆蓋
4. 測完把「自動將變更寫入 XMP」改回你原本的設定。

## 回報

把每一項打勾／打叉，有問題的附截圖。尤其是 **A-3 色標的顏色**，這會決定要不要加一個「色標名稱」的設定。
